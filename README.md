# Team Project
# CLTV Branch
#Infotact Solutions || Batch 18 || Group 5


This branch is assigned to the Customer Lifetime Value (CLTV) Analysis phase of the SaaS/E-Commerce Cohort Retention & CLTV Analysis project. My role is to analyze customer purchasing behavior by segmenting customers into different cohorts, calculating key metrics such as Average Order Value (AOV) and Purchase Frequency, and using these metrics to determine the historical Customer Lifetime Value (CLTV) for each segment. The insights generated from this analysis will help evaluate customer value and support data-driven business decisions.
